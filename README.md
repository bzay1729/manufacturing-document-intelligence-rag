# Manufacturing Document Intelligence & RAG Platform

An end-to-end Document AI and Retrieval-Augmented Generation (RAG)
system for processing, searching, and querying manufacturing and
quality documents.

## Current Development Stage

### Milestone 1 — Document Ingestion

Current goal:

- Load digital PDF documents
- Extract text page-by-page
- Preserve document and page metadata
- Inspect extraction quality

Future stages will include:

- OCR for scanned documents
- Text cleaning
- Chunking
- Embeddings
- Vector search
- Retrieval evaluation
- RAG question answering
- Source citations
- FastAPI
- Streamlit
- Docker
- CI/CD
- Cloud deployment
